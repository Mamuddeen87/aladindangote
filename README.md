# Aladin Dangote – Portfolio Website

This is a modern, single-page portfolio website for **Aladin Dangote**, a musician, dancer, stage performer, MC, and event professional.  
The website features a dark, luxury design with responsive layouts, image carousels, and direct WhatsApp booking integration.

---

## Features

- Fully responsive (mobile & desktop)
- Dark luxury UI with gold accent colors
- Hero section with fading image carousel
- Square advert / performance carousel
- Services displayed in card layout
- WhatsApp “Book Now” buttons
- Floating WhatsApp contact button
- Mobile navigation menu
- Social media links section

---

## Technologies Used

- HTML5  
- Tailwind CSS (CDN)  
- JavaScript (Vanilla)  
- Google Fonts (Inter & Poppins)  
- Font Awesome Icons  

---

## Sections Included

- Navbar
- Hero Section
- About Section
- Advert / Performance Carousel
- Services Section
- Contact Section
- Media / Social Handles
- Footer

---

## Setup & Usage

1. Download or clone the project
2. Open `index.html` in any modern browser
3. Replace images and links as needed
4. Deploy using any static hosting service

---

## Booking & Contact

All “Book Now” buttons link directly to WhatsApp for instant communication with clients.
